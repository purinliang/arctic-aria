# Release v0.7.0

Status: prepared on `agent/feat-discord-vercel-interactions`; pending PR to
`main` and release tag `v0.7.0`.

## Release Title

```text
Release v0.7.0: deploy Discord interactions through the web app
```

## Release Text

```text
Release v0.7.0 moves the Discord interaction runtime into the Next.js web app so Discord can run through Vercel instead of a separate local bot server.

Add Vercel-ready Discord API routes for public HTTP Interactions at /api/discord/interactions and internal message push at /api/internal/discord/messages, while preserving /bind, /idea, Settings Send Test, account-binding persistence, idea capture, signature verification, and outbound Discord direct messages.

Remove the standalone apps/discord-bot package, merge Discord environment configuration into apps/web, move command registration to pnpm --dir apps/web discord:register-commands, and update Discord runbook, deployment, environment, architecture, feature, and roadmap docs for the web route runtime.

Add focused web-side tests for Discord signature verification, interactions, message push, and repository binding behavior so the Vercel route implementation stays covered.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
