## PR Summary

### Summary

Release v0.4.0 adds the first usable core feature foundations after
authentication: memories, routines, projects, shared UI primitives, and
feature-based documentation.

### Changes

- Add memories backend, database migration, service tests, dashboard pinned
  memories, suggestions, category management, and memory add/edit flows.
- Add routines backend, database migration, service tests, routine page, routine
  editor, and dashboard routine actions.
- Add projects backend, database migration, service tests, project list page,
  project detail page, milestones, tasks, subtasks, project editor, and project
  dashboard card.
- Replace the earlier task/plan prototype direction with the
  project/milestone/task/subtask model.
- Add optimistic dashboard command flow with per-item pending state and shared
  error notifications.
- Add shared web UI primitives for buttons, cards, dialogs, inputs, lists,
  panels, tags, switches, notifications, colors, and text.
- Refactor web source organization around feature directories and shared UI
  components.
- Move navigation/user actions into the sidebar and refine responsive sidebar
  behavior.
- Fix pinned memory suggestion pinning and pinned memory action/icon layout.
- Standardize expandable list item behavior and card/list layout patterns.
- Reorganize docs around feature modules instead of core/interface layers.
- Add agent workflow rules for generated files, branch discipline, refactor
  discipline, optimistic UI, shared components, and split layouts.

### Verification

### Notes

- Deployment/database environments need migrations `0002` through `0005`
  applied after the v0.3.0 database state.
- `DATABASE_URL` and `AUTH_SESSION_SECRET` are still required for deployed
  auth/database behavior.
- OAuth, password reset, rate limiting, server-side session revocation, full
  project scheduling logic, and AI-assisted project planning remain deferred.
