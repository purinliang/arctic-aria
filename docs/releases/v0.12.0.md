# Release v0.12.0

## Release Title

```text
Release v0.12.0: refine the daily planning workspace
```

## Release Text

```text
Release v0.12.0 refines the daily planning workspace after the v0.11.5 scheduling release.

The release adds routine groups, moves routine and memory organization into right-side panels, and refocuses project detail pages around milestone progress, selected milestone tasks, and compact project metadata. Today now keeps Daily Review as a header-level summary, shows routines before pinned memories in the right column, visualizes task/routine progress against local day progress, and uses underlined list titles instead of space-consuming right-arrow jump buttons. The release also adds shared progress and popover components, tightens list and dialog spacing, and updates the project, routine, memory, and dashboard UI docs to match the current workspace design.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
