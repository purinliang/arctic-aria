# Release v0.6.0

Status: prepared on `develop`; pending merge to `main` and release tag
`v0.6.0`.

## PR Title

```text
Release v0.6.0: add Discord idea capture and settings foundations
```

## PR Summary

### Summary

Release v0.6.0 adds the first usable Discord bot prototype, expands Settings
into preferences and account integrations, and hardens the web app UI after the
project-centered v0.5.x releases.

### Changes

- Add Discord HTTP Interactions app under `apps/discord-bot`.
- Add Discord `/idea` command for quick idea capture.
- Store Discord-captured ideas in Neon PostgreSQL.
- Add read-only Ideas page in the web app.
- Add Discord account binding from Settings through `/bind code:<code>`.
- Add outbound Discord message push support.
- Add Settings `Send Test` action for manual Discord direct-message
  verification.
- Add Discord bot environment examples, local runbook guidance, and command
  registration notes.
- Require `AUTH_SESSION_SECRET` without insecure fallback.
- Remove sensitive auth/user fixture data and reduce sensitive server logging.
- Add user preferences for theme, language, and time format.
- Add opt-in Simplified Chinese localization foundation.
- Keep English as the default language while Chinese translations remain
  incomplete.
- Add shared localized Arctic Aria brand text.
- Hide unfinished Google sign-in and forgot-password placeholders.
- Add routine recurrence simplification for daily, weekly, monthly, every 14
  days, every 30 days, and fixed-day cycles.
- Add typed app-styled time picker behavior with time preview and user time
  format preference.
- Add long date formatting with localized weekday text.
- Simplify memory categories by removing category period behavior.
- Add built-in memory categories with fixed icons and localized display text.
- Backfill built-in memory categories for existing accounts.
- Remove hard-coded dashboard pinned-memory category filtering.
- Add collapsed database-version metadata while keeping it inspectable for
  debugging.
- Move database migrations to `apps/infrastructure/database/migrations`.
- Add and refine Discord binding cache behavior in Settings.
- Improve sidebar order, pinned project rows, theme/sign-out rows, scrollbar
  behavior, close-button spacing, and mobile overlay behavior.
- Fix mobile sidebar and iOS PWA background behavior so the app background,
  sidebar overlay, and main page remain visible correctly.
- Move shared UI chrome to a neutral grey palette in light and dark mode.
- Document the neutral grey scale and semantic color rule.
- Polish shared dialogs, inputs, pickers, choice groups, dropdowns, list rows,
  notifications, loading, and card/header consistency.
- Update roadmap and related docs for v0.6.0 hardening, Discord, memory
  categories, localization, sidebar, and auth placeholder direction.

### Notes

- Deployments need `AUTH_SESSION_SECRET` configured explicitly.
- Discord local development still uses an HTTP Interactions server exposed with
  ngrok or an equivalent public tunnel.
- Discord production deployment location is not finalized.
- Chinese localization is opt-in and still incomplete.
- Ideas are view-only in the web app; add/edit/triage workflows are deferred.
- Daily review, Discord reminders, Redis, and broader database/concurrency
  review remain future work.
