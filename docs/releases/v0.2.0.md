## PR Summary

### Summary

- Add the first Next.js web dashboard prototype under `apps/web`
- Build an interactive dummy-data daily plan dashboard for tasks, routines,
  review, and rewards
- Add dashboard planning docs under `docs/interface-layer/web-dashboard/prototype.md`
- Clarify agent collaboration/context rules in `AGENTS.md`

### Dashboard Changes

- Add dark-mode-first dashboard with light mode toggle
- Add hamburger sidebar with Dashboard, Tasks, Routines, and Settings
  placeholders
- Add task cards with expandable subtasks, subtask descriptions, weight circles,
  and circular progress
- Add routine cards with `done`, `reminding`, `pending`, and `skipped` states
- Add review dialog with completed work, partial progress, unfinished/skipped
  items, gold, and treasure chest preview
- Keep all prototype data local and non-persistent

- `pnpm lint`
- `pnpm build`
