# Release v0.8.1

## Release Title

```text
Release v0.8.1: harden database migration deployment
```

## Release Text

```text
Release v0.8.1 hardens the database deployment path after v0.8.0.

The release records the local, preview, and production Neon database split, documents the current Vercel CD setup, and keeps the Vercel project-root build command aligned with production: pnpm build && pnpm db:migrate.

Migration runs now record running, success, and failed states in schema_migration_runs. Failed validation or SQL runs are written with a safe failure stage and message when the audit table is available, while still returning a non-zero exit code so Vercel blocks the deployment.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
