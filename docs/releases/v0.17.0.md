```text
Release v0.17.0 adds Aria Chat with user-owned Google Gemini credentials, a compact floating conversation window, seven-day message history, browser caching and clear retryable errors. Money gains compact monthly expense tracking, category filters, separate currency totals and history-ranked note suggestions. Travel Shopping remains hidden pending human review; Progress remains hidden on development builds.

The release preserves the v0.16.1 demo-entry fix. Production's credential-encryption secret is configured, and the existing Vercel deployment pipeline applies migrations through 0045 before promotion. Real-key model access and browser password-manager behaviour remain manual verification items.
```
