# Release v0.12.1

## Release Title

```text
Release v0.12.1: polish responsive workspace details
```

## Release Text

```text
Release v0.12.1 polishes the responsive workspace after the v0.12.0 daily planning release.

The release tightens mobile project list width, standardizes list item typography, due-date wording, auth typography, memory suggestion copy, and Discord bound-account controls. It also narrows split right panels to 20rem, keeps the sidebar and workspace centered together on very wide screens, hides empty built-in memory categories from filters, and updates the recent UI, Settings, sidebar, and scheduling docs to match the current behavior.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
