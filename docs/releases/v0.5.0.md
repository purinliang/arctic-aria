# Release v0.5.0

Status: released on `main` and tagged as `v0.5.0`.

## PR Title

```text
Release v0.5.0: stabilize project workflows and web app foundations
```

## PR Summary

### Summary

Release v0.5.0 turns the current project, memory, routine, dashboard, and
infrastructure work into a more stable web-app baseline after v0.4.0.

### Changes

- Add pinned project shortcuts in the sidebar.
- Add project sidebar pin persistence in Neon PostgreSQL.
- Allow project tasks without milestones.
- Add memory category descriptions.
- Add Settings page with app/database version metadata.
- Add signed-out app/database version metadata footer.
- Add app build metadata from Git branch, tag, commit, and source state.
- Record migration run metadata.
- Add database migration file checksums.
- Use a whole-history database schema hash as the database version.
- Refuse migration runs when the database is ahead, migration order differs, or
  migration checksums drift.
- Refactor dashboard into app shell plus normal dashboard page.
- Move sidebar, theme, notifications, and page switching into shared app-shell
  ownership.
- Flatten shared web components and add shared form, dialog, notification,
  loading, list, and version-status primitives.
- Add shared date picker, time picker, choice group, text area, number field,
  and selection controls.
- Improve UI consistency across pages by routing buttons, panels, cards,
  dialogs, inputs, lists, text styles, notifications, and loading states
  through shared components.
- Polish interaction details, including consistent hover backgrounds, clipped
  list-row radius inside cards and panels, continuous sidebar/dropdown row
  groups without hover gaps, and animated stacked notifications.
- Route auth and management errors through shared notifications.
- Add Arctic Aria loading and 404 surfaces.
- Improve dashboard task, routine, and pinned-memory checkbox flows.
- Fix dashboard task completion timeout with lightweight task-status actions.
- Fix pinned memory replacement/control sizing and selectable row hover
  clipping.
- Improve list item jump-button behavior and loading rows.
- Refresh feature docs into overview/data-model/ui/web-implementation
  structure.
- Add docs for web UI components, theme, sidebar, Redis roadmap, database
  lifecycle, and migration/version behavior.

### Verification

- Manual dashboard task completion timeout check passed.
- Manual list/sidebar/dropdown hover check passed.
- Manual migration checksum run passed.
- `pnpm --dir apps/web test`
- `pnpm --dir apps/web lint`
- `pnpm --dir apps/web build`
- `git diff --check`

### Notes

- Release was merged to `main` from `develop` and tagged as `v0.5.0`.
- For any deployment built from this release, run
  `pnpm --dir apps/web db:migrate` from the exact release commit so the
  database version audit row matches the deployed app.
