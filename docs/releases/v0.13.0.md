# Release v0.13.0

## Release Title

```text
Release v0.13.0: add Events and workspace polish
```

## Release Text

```text
Release v0.13.0 adds first-class Events for one-time scheduled plans, with a dedicated Events page, Today visibility, Daily Review context, event filtering, location support, and decimal-hour estimated durations.

The release also improves Today metadata layout for events and routines, softens list dividers with a dedicated divider border token, and keeps Settings Discord binding status fresh through cache-aware updates. It includes the database migrations, schema and feature docs, and tests needed for the new Events workflow.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
