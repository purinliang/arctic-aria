# Release v0.11.2

## Release Title

```text
Release v0.11.2: document Neon Singapore migration
```

## Release Text

```text
Release v0.11.2 records the Neon Singapore migration work after v0.11.1.

The release adds a database-owned helper for copying Arctic Aria's public schema between Neon regions with unpooled URLs, PostgreSQL client version checks, destination reset confirmation, restore validation, and migration verification.

It also documents the measured latency improvement from colocating the Vercel backend and Neon database in Singapore, and moves tab-switch loading benchmarks into the Performance docs so route-navigation decisions and benchmark evidence stay together.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
