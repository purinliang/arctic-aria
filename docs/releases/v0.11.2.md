# Release v0.11.2

## Release Title

```text
Release v0.11.2: document Neon migration and standardize errors
```

## Release Text

```text
Release v0.11.2 records the Neon Singapore migration work and standardizes action failure notifications after v0.11.1.

The release adds a database-owned helper for copying Arctic Aria's public schema between Neon regions with unpooled URLs, PostgreSQL client version checks, destination reset confirmation, restore validation, and migration verification.

It also documents the measured latency improvement from colocating the Vercel server and Neon database in Singapore, and moves tab-switch loading benchmarks into the Performance docs so route-navigation decisions and benchmark evidence stay together.

Action failures now use shared notification classes for database connection failures, database update failures, missing or invalid parameters, missing targets, and unknown server internal errors. Feature validation still keeps clear field-level messages for user-fixable input problems such as empty titles, invalid dates, and overly long text.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
