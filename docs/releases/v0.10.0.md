# Release v0.10.0

## Release Title

```text
Release v0.10.0: add data governance and settings foundations
```

## Release Text

```text
Release v0.10.0 standardizes project and routine data governance after the route-backed v0.9.0 workspace release.

The release standardizes project, task, milestone, and routine persistence around consistent `deleted_at` soft deletion. It removes retired project/task fields such as priority, scheduled date, task status variants, skipped/blocked state, and task dependency storage from the current schema direction, with project task done state derived from `completed_at`.

The release also makes descriptions optional across core add/edit flows with render-only default text, improves Today empty states and routine recurrence copy, prepares timezone preference storage while keeping user-facing timezone controls disabled as system-only, and aligns the Discord bound-account row with the shared password input style.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
