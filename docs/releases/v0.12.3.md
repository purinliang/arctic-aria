# Release v0.12.3

## Release Title

```text
Release v0.12.3: polish Today and project detail views
```

## Release Text

```text
Release v0.12.3 polishes the Today and project detail experience after the v0.12.2 routine recurrence release.

The release separates Daily Review delivery from next-day scheduling windows, moves Today guidance into a compact Progress panel, and keeps Discord review summary text out of the main Today page. It also refines project detail into project-level and milestone-level views, updates milestone overview editing and progress display, tightens project switcher behavior, and refreshes related dashboard, project, routine, Discord, and release workflow documentation.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
