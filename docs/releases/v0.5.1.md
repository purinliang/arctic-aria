## PR Summary

### Summary

Release v0.5.1 is a focused hotfix after v0.5.0. It corrects production
version metadata display, improves small dashboard/project/memory UI details,
and records the next v0.6.0 stabilization direction.

### Changes

- Show exact release tags without appending commit hashes.
- Hide database version metadata on aligned release builds.
- Keep database version metadata visible on non-release builds, including the
  expected schema hash.
- Derive hotfix branch app versions from the hotfix version, such as `v0.5.1`,
  instead of the next minor development version.
- Rename the Settings metadata card to `App Information` and use an info icon.
- Standardize memory suggestion and project pin actions as icon-only outline
  buttons.
- Remove noisy dashboard header count metadata from project tasks, routines,
  and pinned memories.
- Clarify missing project and milestone date validation so empty required dates
  ask the user to select a date, while malformed dates still show the real-date
  format error.
- Organize the README document map and correct previous release record status.
- Record v0.6.0 stabilization scope and deferred memory UI follow-ups.
- Record multilingual support, especially Chinese, as later future work.
