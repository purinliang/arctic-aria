## PR Summary

### Summary

Release v0.3.0 prepares the first usable auth foundation for Arctic Aria.

### Changes

- Add username/password registration and login.
- Store users in Neon PostgreSQL.
- Hash passwords with bcrypt.
- Add shared frontend/backend auth validation.
- Add database migration runner and initial `users` migration.
- Add duplicate username race protection.
- Add 30-day signed auth session cookie.
- Add dashboard sign out.
- Add auth implementation notes and updated roadmap/docs references.

### Verification

- Manual migration passed.
- Manual sign up passed.
- Manual sign in passed.
- Manual invalid username login failed as expected.
- Manual refresh after login kept session.
- Manual sign out returned to auth screen.
- `pnpm test`
- `pnpm lint`
- `pnpm build`
- `git diff --check`

### Notes

- `AUTH_SESSION_SECRET` should be configured for deployment.
- OAuth, password reset, rate limiting, and server-side session revocation are
  deferred.
