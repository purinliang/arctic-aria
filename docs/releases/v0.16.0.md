```text
Release v0.16.0 adds Try demo directly to both sign-in and sign-up, with a shared Trying demo loading screen and one-time ?demo=true entry that preserves existing signed-in sessions. It aligns the event group chooser with routines and improves AI collaboration guidance with focused agent docs, a repeatable web verification script, and concurrent work rules.
```
