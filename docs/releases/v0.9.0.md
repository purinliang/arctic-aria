# Release v0.9.0

## Release Title

```text
Release v0.9.0: add route-backed workspace navigation and UI polish
```

## Release Text

```text
Release v0.9.0 adds route-backed workspace navigation so main workspace views can be opened directly by path while keeping sidebar switching fast enough for production use.

The release adds workspace routes for Today, Projects, Routines, Memories, Ideas, and Settings, rewrites workspace paths through the main app shell, refreshes the Arctic Aria 404 page, keeps sign-out routing predictable, and documents tab-switch benchmark results comparing the route and non-route implementations.

It also polishes several visible UI flows: auth submit buttons stay welcoming, shared list rows are more compact, Discord binding rows and command copy are clearer, project timeline editing now separates Start date from Deadline or No fixed deadline, and memory experience text supports category-specific wording through localization-friendly message config.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
