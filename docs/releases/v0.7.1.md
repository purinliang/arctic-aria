# Release v0.7.1

## Release Title

```text
Release v0.7.1: fix Discord Settings test message
```

## Release Text

```text
Release v0.7.1 fixes the Settings Discord test-message flow after v0.7.0.

Settings now sends the test DM through the web server delivery logic directly instead of self-fetching the protected internal message endpoint, avoiding misleading message-push secret rejection errors.

User-facing notifications now stay generic, while server logs keep safe missing-config details for debugging. Focused tests, docs, and web environment examples were updated for the corrected flow.
```
