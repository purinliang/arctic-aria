# Release v0.11.1

## Release Title

```text
Release v0.11.1: add admin diagnostics and interaction fixes
```

## Release Text

```text
Release v0.11.1 adds internal diagnostics and tightens interaction polish after v0.11.0.

The release adds an admin-only latency diagnostics panel in Settings so production frontend, backend, and database latency can be measured without exposing developer tools to normal users.

It also resolves Daily Review timezone fallback by storing the browser-resolved timezone, moves developer diagnostics to the end of Settings, scrolls dropdowns to the selected option when opened, fixes input and picker label hit areas, and records the sub-agent workflow rules used during the release.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
