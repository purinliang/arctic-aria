# Release v0.12.2

## Release Title

```text
Release v0.12.2: add once and yearly routine rules
```

## Release Text

```text
Release v0.12.2 improves routine recurrence control after the v0.12.1 workspace polish release.

The release adds Once as the default routine repeat rule, adds a Yearly option for fixed calendar-date routines, and keeps Fixed interval stable while typing values such as 30, 70, or 300. It also updates routine import templates, recurrence validation, scheduling logic, database constraints, tests, and routine documentation to match the new rule behavior.
```

Use the release title as the PR title and main release commit title. Use the
