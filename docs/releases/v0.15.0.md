# Release v0.15.0

## Release Title

```text
Release v0.15.0: add recurring event instances and design system polish
```

## Release Text

```text
Release v0.15.0 adds recurring Event definitions with generated Event instances, instance date filters, and per-instance reschedule or cancel actions. It also separates task and routine completion records, improves routine instance generation, and updates the database schema, feature docs, and tests for the new recurring schedule model.

The release also adds the developer-only Design page, persisted Developer mode, shared paged lists, compact manager lists, content sections, and tokenized spacing, typography, and color rules. It polishes split-panel layouts, list metadata truncation, disabled and text-input colors, compact pagination, milestone switcher cursors, and shared UI documentation so routine, event, project, memory, idea, and settings surfaces stay visually consistent.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
