## PR Summary

### Summary

Release v0.6.1 is a focused patch after v0.6.0. It fixes dashboard checkbox
race behavior, improves mobile project-title layout, and keeps the auth loading
screen aligned with cached language and theme preferences.

### Changes

- Keep dashboard routine and pinned-memory checkboxes reversible while backend
  updates are pending.
- Ignore stale dashboard checkbox responses so older responses do not overwrite
  newer user clicks.
- Add focused optimistic-update coverage for dashboard routine and pinned-memory
  checkbox behavior.
- Polish the mobile project detail title so controls stay on the first line and
  long project names truncate cleanly on the second line.
- Focus and select the typed time input when the time picker opens.
- Show clearer typed time examples with `9:30PM or 21:30`.
- Center auth loading on the mobile viewport.
- Use the cached language preference before hydration so refresh loading does
  not flash mixed English and Chinese text.
- Update related UI and feature docs for the patch behavior.
