# Hotfix v0.15.1

## Release Title

```text
Hotfix v0.15.1: add demo sign-in and password changes
```

## Release Text

```text
Hotfix v0.15.1 adds a demo sign-in link and password changes in Settings. Visiting the app with ?mode=demo fills the sign-in form with the public demo account credentials. Signed-in users can change their password in a compact dialog by verifying their current password and confirming a new one.

The release also corrects Git-derived hotfix versions to target the next patch release and use the newest release in the branch history when tags are older. It documents the hotfix version and PR naming rules.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
