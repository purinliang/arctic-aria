# Release v0.8.0

## Release Title

```text
Release v0.8.0: add editable Ideas and web UI polish
```

## Release Text

```text
Release v0.8.0 turns Ideas into an editable web surface. Users can now add, edit, and archive-delete ideas from the Ideas page, while Discord /idea capture continues to write into the same Ideas model.

The release adds ownership-safe Ideas backend actions, repository methods, service coverage, localized UI messages, immediate list updates after successful saves and deletes, and updated Ideas documentation for overview, UI, data model, and implementation behavior.

It also improves the shared web UI foundation with a reusable CRUD editor dialog shell, consistent pending text states, safer dialog and picker interactions, form focus styling, custom scrollbars, sidebar/browser cache polish, PWA icon cleanup, and current documentation for the shared UI rules.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
