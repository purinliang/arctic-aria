# Release v0.14.0

## Release Title

```text
Release v0.14.0: add template-driven workspace editing
```

## Release Text

```text
Release v0.14.0 adds template-driven editing workflows for Projects, Routines, and Events. Project templates can now create or update a full project tree with explicit project, milestone, and task operations, while Routine and Event dialogs can parse, preview, and save reusable text templates from the normal add/edit flow.

The release replaces the old administrator-only import tools with user-facing template editors, refreshes the related feature documentation, and adds coverage for the new parsing, preview, ownership, and save behavior. It also polishes shared dialog scrolling, template editor layout, cursor and input hover states, Settings diagnostics row styling, and the Events page all-filter experience.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
