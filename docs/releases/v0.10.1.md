# Release v0.10.1

## Release Title

```text
Release v0.10.1: fix Discord bound account display
```

## Release Text

```text
Release v0.10.1 fixes the Discord bound account display after v0.10.0.

The release renders the bound Discord account id as a disabled password-style field so it cannot be selected or edited, while keeping the view/hide button clickable.

It also keeps Send Test and Unbind grouped together so they stay beside the field on wider screens and wrap together on smaller screens.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
