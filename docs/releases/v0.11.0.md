# Release v0.11.0

## Release Title

```text
Release v0.11.0: add Discord scheduled reminders and Daily Review
```

## Release Text

```text
Release v0.11.0 makes Discord delivery a scheduled part of Arctic Aria.

The release adds a shared Discord notification pipeline, automatic Daily Review messages, routine reminders backed by routine instance reminder timestamps, and a Cloudflare cron worker that invokes the web app's scheduled notification route.

It also hardens auth and settings interaction races, improves Today Review layout and message text, moves database migrations and migration helpers under `apps/database`, adds the web deploy command, and records a human-readable current database schema snapshot while keeping migration history as the source of truth.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
