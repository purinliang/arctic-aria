# Release v0.11.5

## Release Title

```text
Release v0.11.5: stabilize Today scheduling and date handling
```

## Release Text

```text
Release v0.11.5 stabilizes Today scheduling and local date handling after the v0.11.4 import release.

Today now keeps selected project tasks and routine instances visible after completion, refills Today task slots in the same response after deletion, creates routine instances when routines are saved, and resolves Today from the user's stored timezone before falling back to UTC. The release also adds the project task daily selection table, shares Postgres date/time field mapping across project and routine mappers, adds memory pin controls on the Memories page, and polishes developer tools, latency metrics, project title truncation, and import template guidance.
```

Use the release title as the PR title and main release commit title. Use the
release text as the PR body and main release commit body.
